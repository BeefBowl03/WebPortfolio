02 / WHO YOU'RE HIRING

About

I'm Celso. I've spent the last four years building and maintaining e-commerce sites and internal tools for businesses that actually depend on them — a US event-linens retailer mid-way through a full theme migration, an HVAC parts distributor moving a million SKUs, an Australian fragrance brand, a South African homeware chain, a Dutch-language course platform.

And internal tools: React and TypeScript apps that take a repetitive manual process and turn it into a form, a queue, and a database row.

I work directly with the person who owns the problem. No account manager in the middle. I'd rather ask three blunt questions up front than guess at a spec and rebuild it twice.

02

CV Linens

Store features built to survive a full theme migration

This store is moving off the legacy Dawn theme onto a new Dwell/Horizon theme, and the usual cost of that is rebuilding every custom feature by hand. I build the features as Shopify app theme extensions instead — app blocks and app embeds that carry their own logic, UI, CSS, and JS — so they're theme-independent and come through the migration without rework. The working standard is blunt: a feature that lands automatically in the new theme is ideal, one or two migration steps is acceptable, anything needing repeated manual work per feature gets rejected. Modular sections and snippets are the fallback, direct theme edits the last resort, and CSS stays scoped per feature rather than global. Also handling ADA/WCAG accessibility remediation across the store.

Role Shopify app extension development, theme migration engineering, accessibility remediation
